Processing Pipeline

A weather model does not get rainfall wrong at random. It gets it wrong in patterns that depend on what kind of weather is happening. This system classifies the weather first, then applies a correction built for that situation, then reports calibrated odds of dangerous rain.

    Method

    A weather model does not get rainfall wrong at random. It gets it wrong in patterns — too dry over hills, too wet during a lull. This system classifies the weather first, then applies a correction built for that situation, then reports calibrated odds of dangerous rain.

      Known Limitations

      • The weather-type definitions are stand-ins. Simplified placeholders, not the official published criteria.
      • The labels are rules, not truth. Agreement with them measures whether the classifier learned the rule, not whether the rule is right.
      • Training and forecasting see different labels. The rules need the measurement, which does not exist when a real forecast is made.
      • The advisory cut-points are provisional. They have not been agreed with any weather agency.
      • Rare thresholds may be unfittable. If a training period holds no 204.4 mm days, that model falls back to a base rate.
      Every value is computed from the connected dataset at request time. Nothing is pre-written, and nothing is filled in when the data is missing.
